# Pokémon: My Favorite Series

## Overview
**Pokémon** is a massive media franchise centered on fictional creatures called "Pokémon". Trainers catch and train them to battle each other for sport.

## Top 3 Favorite Pokémon
1. **Mudkip** (Water type)
2. **Turtwig** (Grass type)
3. **Charmander** (Fire type)

## Key Features of the Series
* **Exploration** across diverse fictional regions.
* **Strategic battles** using different element types.
* **Creature collecting** to complete the Pokédex.
